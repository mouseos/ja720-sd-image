JA720 Linux 導入手順 (Pocket Challenge 4 / JA720)
================================================

これはベネッセ「ポケットチャレンジ4年」(JA720) の純正ローダを使って
Linux を内蔵ストレージへ書き込み、起動するためのファイル一式です。
カーネルは mainline 系 Linux (mouseos/linux-ja720) です。

同梱ファイル
------------
- JA720LNX.BIN : Linux カーネル + initramfs の一体イメージ
- SDUPDATE.INI : 純正ローダの SD アップデート用指定ファイル
- README.txt   : このファイル

必要なもの
----------
- microSD カード (FAT16/FAT32 でフォーマット済み)
- USB ケーブル (PC と JA720 を接続し、SSH 接続に使います)

導入手順
--------
1. JA720LNX.BIN と SDUPDATE.INI を microSD カードのルートへコピーする。
2. カードを JA720 に挿し、電源を切る。
3. MENU ボタンを押しながら電源を入れる (SD アップデートモード)。
   画面に "SD Update!" と進捗 (%) が表示されれば成功です。
   ※ 起動方法の詳細は実機での確認を前提としています。うまく入らない
     場合は、配布元の案内を確認してください。
4. 書き込みが終わると自動で再起動し、Linux が起動します。
   画面にログが流れ、最後にログインシェルが出ます。

使い方 (SSH)
------------
1. USB ケーブルで PC と接続する。PC 側に USB ネットワーク
   (CDC Ethernet / RNDIS) として認識されます。
2. PC 側のアドレスを 192.168.7.1/24 に設定する。
3. ssh root@192.168.7.2 (パスワード: ja720)
4. 初回ログイン後、必ず passwd でパスワードを変更してください。

注意・安全について
------------------
- この書き込みは内蔵ストレージの「カーネル領域」だけを置き換えます。
  ローダ (ブートコード) 自体は書き換えません。そのため、万一 Linux
  が起動しなくても、同じ手順で純正カーネルファイルを書き戻せば
  復旧できます。
- SD アップデート中は電源を切らないでください。
- これは開発中のソフトウェアです。大事な学習データは事前に
  バックアップしてください。

戻し方 (純正に戻す)
--------------------
純正カーネル (JA720XXX.ROM 相当) を同じ SDUPDATE の仕組みで
書き戻すことで復旧できます。詳細は配布元リポジトリを参照してください。
